# Contributing to Space_program

Thank you for contributing to Space_program. Please follow these guidelines:

1. **Fork and branch** — create a feature branch from `master`.
2. **Code style** — follow existing HTML/CSS/JS conventions used in the repository.
3. **Tests** — add or update automated checks where applicable (HTML validation, link checks).
4. **Commits** — use clear, imperative commit messages.
5. **Pull requests** — open a PR against `master` with a description of changes and any relevant issue references.
6. **Review** — be responsive to review feedback and CI results.

By contributing, you agree that your contributions are licensed under the MIT License.
